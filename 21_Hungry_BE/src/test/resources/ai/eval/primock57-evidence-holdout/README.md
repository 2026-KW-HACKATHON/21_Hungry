- 첫 사례는 조건부 약물·추가 검사·재방문, 둘째는 부위 정정·의료진 요약과 환자 진술 충돌·여러 약·조건부 재방문을 포함한다.

- 번역/의미 평가는 AI 작성 및 원문 대조 단계. 개발자 검토 대기, **의료진 검증 아님**. 불명확 태그·수치·약명·조건·화자 관계를 유지했고 한국 처방으로 바꾸지 않았다.

- 이 두 사례의 대사/기대 답은 프롬프트 예시로 사용하지 않는다. 평가 후 후보를 수정한다면 개발 자료로 편입하고 새 별도 평가를 확보해야 한다.
