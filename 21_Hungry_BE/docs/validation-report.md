## 변경 근거

## 구현 기본값과 주의

- 현재 문서에서 선택한 API 신규 경로/enum명, 국내010정규화,1900~현재연도,가입후로그인,전체기준월집계·목록만내일정필터는 구현 계약이다.
- 기존 Source·Task 예시에도 documentType·개인 상태 필드를 반영했다. 예시는 독립된 스냅샷이며 canAccept 등은 실제 서버 계산값을 사용한다.
- 메인Today 제거와 반복알림설정 제거는 API 폐기로 명시했다. 직접추가제한은 AI/처방 반복 생성 전체를 없애는 뜻이 아니다.
- 부모 정보를 나중에 수정하는 기능은 제공하지 않는다. 기존 배포 데이터의 미완료 부모 정보는 이관 단계에서 해결한다.
- 목표 SQL은 빈 검증 DB 전용이다. 이미 적용된 V1/V2를 교체하지 않는다.
