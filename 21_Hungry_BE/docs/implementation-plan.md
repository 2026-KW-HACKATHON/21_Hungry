## 기술 위험을 앞당겨 확인

단계 1에서 HTTPS 녹음과 실제 푸시의 작은 시험을 별도로 수행한다. 전체 기능을 앞당겨 구현하는 것이 아니라 Origin·권한·코덱·실기기 가능 여부를 확인하는 것이다. 배포 자격증명과 기기가 없으면 로컬 기반을 완료하고 외부 시험을 BLOCKED로 기록한다.

## 모든 단계의 공통 완료 조건

- API 경로·요청·응답·오류와 문서 일치. 기본값만 구현한 항목은 PARTIAL로 기록.
- 인증·인가, 일정 잠금, 멱등성, 업무 이력·outbox를 관련 기능과 함께 구현.
- 테스트 명령·결과 기록. 단순 문법 검사와 실제 경쟁/기기 시험 구별.
- 이전 사용자 데이터·문서 Blob·캐시 정리 규칙 프론트에 전달.
- 적용된 Flyway 파일 수정 금지. 필요한 변경은 새 migration.
- 단계 종료 시 progress.md/API 표 갱신. 다음 작업은 요청받은 범위에서 진행.
