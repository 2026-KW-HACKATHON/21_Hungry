# v1.8.1 고정 평가 기준 (실호출 전)

2026-10-09. AI 원문 대조, 임상 검증 아님. 운영 승격 기준 변경 없음.

- 형식: 통신/잘림/JSON/스키마/ID·위치/내부 필드 관계를 각각 기록한다. 원시 JSON 유효와 전체 서비스 파싱 성공은 다르다. 실패 응답의 raw 의미 검토도 하되, 성공 전달·보존으로 세지 않는다.
- 의미 단위: 하나의 주체-속성-값 또는 하나의 행동/약 후보. 같은 오류가 summary/details/item에 반복되면 한 오류 ID에 surfaces를 기록한다. 서로 다른 약·용량·조건은 별도 단위다. 사실 오류(FF), 근거 없는/잘못된 후보(UC), 필요한 사실 누락(MF), 후보 누락(MC), 불충분 근거(EV)를 구분한다. 틀린 값 대체는 FF/UC로 세며 같은 값의 누락을 중복 집계하지 않는다. 출력 자체가 없는 전면 실패는 DELIVERY_BLOCK로 별도 표시한다.
- 심각도: CRITICAL=복용량/약 선택·병용/중단·긴급 행동 조건을 바꿀 수 있는 오류. MAJOR=필요한 치료·검사·추적·확인 후보/임상 정보 누락, 화자·확실성 변경, 중요 근거 불일치. MINOR=사실·행동이 보존된 중복·장문·표현. MINOR는 전체 의미 PASS를 뒤집지 않는다.
- 정답은 전체 전사. 의료진 note는 참고만 사용한다. 번역/전사 모호함은 AMBIGUOUS_SOURCE이며 확정 정답이나 모델 오류로 세지 않는다. 임상 상식으로 보완하지 않는다.
- 모든 후보/기존 v1.7/v1.8에 동일 적용. 조건부/날짜 미상 실제 가족 행동은 후보를 보존한다. 의료진만 하는 일/이미 진행 중 행동/일반 조언은 새 가족 일정 후보가 아니다. 기존 약을 계속하라는 명시 지시는 이름 미상 확인 후보로 보존하지만 단순 약력은 새 후보가 아니다.
- 계획 기본값 120/30분 자체는 오류가 아니다. 근거 없는 반복/복약 시각, 기본값을 의료 발언으로 제시하면 오류다. 질문과 필요한 답변 모두 근거에 있어야 한다. 서버가 인접 질문을 보완했는지 기록하고, 연결된 발화가 주장 전체를 지지하는지는 별도 검토한다.
- B→C는 고쳐진 오류뿐 아니라 신규 오류/누락을 같은 단위로 기록한다. 검증 모델의 승인이나 파싱 성공을 의미 정답으로 사용하지 않는다.
- 선별 6건: D01, D11, H01, day3_consultation05, day3_consultation08, day1_consultation02. 정정 용량/문서 처방 역할/조건부 행동/대안 약/10일 기간-시각/질문-답변을 포함한다. 공개 3/한국어 합성 3을 따로 집계한다.
- 확장 기준: A와 비교해 CRITICAL 증가 없음, MAJOR 포함 오류·누락 총 단위 감소, 전체 전달 성공 감소 없음. C는 B 대비 같은 기준을 적용한다. 근거 없는 후보를 없애기 위해 필요한 후보를 제거하면 개선으로 상쇄하지 않는다. 개선된 비교군만 기존 20건으로 확장하며 핵심 회귀가 발견되면 승격하지 않는다.
- 최종 새 입력은 후보 파일/모델/설정을 고정한 뒤 확보한다. 과거 v1.8 별도4는 이미 검토된 개발 자료로 표시한다. 새 결과를 보고 후보를 수정하면 홀드아웃 지위를 잃는다.
- 전체 PASS는 형식 통과 + 관찰 CRITICAL/MAJOR 0. 체크한 원자 단위와 관찰 이슈 수를 공개한다. 전수 임상 사실 재현율·안전성 인증으로 표현하지 않는다.
