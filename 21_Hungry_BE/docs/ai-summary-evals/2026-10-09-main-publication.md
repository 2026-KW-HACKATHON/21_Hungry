# AI 평가 구현·자료의 main 반영

2026-10-09. 사용자가 main 직접 커밋·푸시 및 자동배포를 명시적으로 승인했다. 실험 후보의 운영 승격은 승인 범위에 포함하지 않는다.

## 범위와 운영 기본값

- 통합 기준: origin/main `11102a8130ccf415aa527ce9f40d3d700d479a2d`. 최신 V07 등 기존 main 변경을 보존한다.
- AI 가이드라인, 버전별 프롬프트, 선택형 근거/의미 분석 경로, 독립 평가 스크립트, 공개 모의·합성 자료, 저장 응답과 비용/판정 기록을 함께 반영한다.
- 실제 기존 main은 `analysis-prompt-v1.0.txt`를 사용했다. 과거 보고서의 ‘운영 v1.1’은 미배포 로컬 작업본 기준이었으며 운영 확인이 아니었다. **기본 legacy/v1.0 및 기존 모델을 유지**한다. v1.1은 `OPENAI_ANALYSIS_PROMPT_VERSION=1.1` 명시 시에만 선택된다. 실험 프로토콜 역시 명시 설정이 필요하다.
- 모델 품질 승격, 외부 API/DB 계약 변경, 신규 migration, 운영 처방/일정 생성, 추가 유료 AI 호출은 하지 않는다. 중요한 의미 오류 때문에 후보 승격 보류 판정은 그대로다.
- 원래 be/develop 작업 폴더의 변경·삭제는 보존한다. 관련 없는 문서 교체·ERD 작업과 비밀 설정은 포함하지 않는다.

## 배포 전 검증

- 격리된 main 작업 트리에서 `gradlew.bat test bootJar --console=plain` 성공: **24 suites / 194 tests / 실패·오류·건너뜀 0**, bootJar 생성 완료. 외부 AI는 mock이며 PostgreSQL 통합 테스트는 로컬 테스트 스키마를 사용했다. 이것은 요약의 임상 의미 정확성 검증이 아니다.
- 기본 v1.0 요청 및 명시 선택 v1.1 요청을 mock HTTP로 각각 확인한다. 기존 동의 없는 프롬프트 승격을 막는 회귀 검사다.
- 동결 자료의 바이트 해시가 Windows/Linux 체크아웃에서 달라지지 않도록 `.gitattributes`에 원본 바이트 보존을 명시한다. 저장 평가 요청·응답이나 동결 프롬프트를 포맷팅해 바꾸지 않는다.
- main push가 기존 `Backend CD`를 트리거한다. 실제 배포 완료는 해당 workflow의 테스트·배포·health check 결과로 별도 확인한다. 이 문서 작성만으로 완료를 주장하지 않는다.
