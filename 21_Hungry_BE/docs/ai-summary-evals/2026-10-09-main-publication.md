# AI 평가 구현·자료의 main 반영

2026-10-09. 사용자가 main 반영·자동배포를 승인한 뒤, **실행 프롬프트 v1.8.1을 기본값으로 사용**하도록 정정했다. main 직접 푸시는 저장소의 PR 필수 규칙으로 거절되었으므로 PR 경로로 반영한다.

## 범위와 운영 기본값

- 통합 기준: 기존 AI 커밋을 최신 origin/main 위에 재배치했다. 최신 V07과 프론트 변경을 보존한다.
- AI 가이드라인, 버전별 프롬프트, 선택형 근거/의미 분석 경로, 독립 평가 스크립트, 공개 모의·합성 자료, 저장 응답과 비용/판정 기록을 함께 반영한다.
- 기존 main은 `analysis-prompt-v1.0.txt`를 사용했다. 과거 보고서의 ‘운영 v1.1’은 미배포 로컬 작업본 기준이었다. 사용자 정정에 따라 **기본 실행을 `semantic-facts-v2`/프롬프트 v1.8.1**로 바꾼다. 모델, 외부 API/DB 계약, migration, 처방·일정 확인 정책은 그대로다.
- v1.8.1은 앞선 실제 평가에서 CRITICAL 약 선택 오류와 새 입력 실패가 남았다. 이번 기본값 선택은 그 오류의 해결이나 의료진 검증을 뜻하지 않는다. 추가 유료 AI 호출은 하지 않는다.
- 원래 be/develop 작업 폴더의 변경·삭제는 보존한다. 관련 없는 문서 교체·ERD 작업과 비밀 설정은 포함하지 않는다.

## 배포 전 검증

- 격리된 작업 트리에서 `gradlew.bat test bootJar --console=plain` 성공: **24 suites / 195 tests / 실패·오류·건너뜀 0**, bootJar 생성 완료. 외부 AI는 mock이며 PostgreSQL 통합 테스트는 로컬 테스트 스키마를 사용했다. 이것은 요약의 임상 의미 정확성 검증이 아니다.
- v1.8.1의 실제 adapter 요청에 새 프롬프트·발화 ID·facts 스키마가 들어가고, 동일 응답 파서가 실행되는지 mock HTTP로 확인한다. legacy/v1.0 및 명시 선택 v1.1 테스트도 유지한다.
- 동결 자료의 바이트 해시가 Windows/Linux 체크아웃에서 달라지지 않도록 `.gitattributes`에 원본 바이트 보존을 명시한다. 저장 평가 요청·응답이나 동결 프롬프트를 포맷팅해 바꾸지 않는다.
- main push가 기존 `Backend CD`를 트리거한다. 실제 배포 완료는 해당 workflow의 테스트·배포·health check 결과로 별도 확인한다. 이 문서 작성만으로 완료를 주장하지 않는다.
